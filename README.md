## Descripción de actvidades

i) El trabajo fue realizado en clases usando programación por pares. Los participantes incluyeron su criterio de diseño y refactorización para cumplir con la tarea solicitada.

ii) El programa simula un robot limpiador que puede limpiar matrices $n * n. Las celdas sucias y la posición inicial del robot son aleatorias, al igual que su movimiento.

iii) Se optimizó el algoritmo para que el robot se mueva por celdas adyacentes que podrían estar sucias en base a una memoria (*Agente basado en modelo*)
